🔧 Проверка настроек бота в BotFather

Важно! Неправильные настройки бота - самая распространенная причина проблем с WebApp.

📱 Как открыть BotFather

1 Откройте Telegram и найдите @BotFather
2 Отправьте команду /mybots чтобы увидеть список ваших ботов
3 Выберите нужного бота из списка

🔍 Проверка основных настроек

1. Проверка токена бота

/mybots → [выберите бота] → Bot Settings → API Token

Что проверить: Токен должен быть активным и не просроченным

2. Проверка Web App URL

/mybots → [выберите бота] → Bot Settings → Menu Button → Web App

Должен быть: https://tonarisun.github.io/botlab/ (или другое ваше приложение)

3. Проверка Inline Mode

/mybots → [выберите бота] → Bot Settings → Inline Mode

Должен быть: Inline mode ON

🛠️ Настройка Web App (если не настроена)

Шаг 1: Включение Menu Button

/setmenubutton

BotFather спросит: "Choose a bot to edit:"

Шаг 2: Выбор бота

Выберите вашего бота из списка

Шаг 3: Настройка кнопки меню

BotFather предложит варианты:

  • "Web App" - выберите этот вариант

Шаг 4: Ввод URL Web App

Введите URL вашего приложения на GitHub Pages:

https://tonarisun.github.io/botlab/

Для других приложений:

  • https://tonarisun.github.io/lead-for-quiz/
  • https://tonarisun.github.io/neon-ai-quiz-tablet/
  • https://tonarisun.github.io/girlsundercode_-ai-assistant-vs-agent/

📋 Полная проверка всех настроек

1 Имя и username бота:
Проверьте, что бот имеет правильное имя и username
2 Description (описание):
Должно быть заполнено и описывать назначение бота
3 About (о боте):
Краткое описание функций бота
4 Botpic (аватар):
Рекомендуется установить аватарку бота
5 Commands (команды):
Настройте команды бота через /setcommands
6 Web App URL:
Должен вести на ваш GitHub Pages URL
7 Inline mode:
Должен быть включен (ON)

🎯 Тестирование после настройки

1 Откройте чат с ботом в Telegram
2 В меню бота должна появиться кнопка Web App
3 Нажмите на кнопку Web App
4 Приложение должно открыться в новой вкладке/окне
5 В консоли должны быть логи инициализации Telegram WebApp

🚨 Возможные проблемы и решения

Web App не открывается

Причина: Неправильный URL
Решение: Проверьте, что URL ведет на index.html вашего приложения

Приложение открывается, но Telegram API недоступен

Причина: Приложение не инициализируется как WebApp
Решение: Проверьте, что скрипт telegram-web-app.js загружается

Кнопка Web App не отображается

Причина: Menu Button не настроена
Решение: Выполните /setmenubutton и настройте Web App

Web App открывается в браузере, а не в Telegram

Причина: Пользователь открыл ссылку вручную
Решение: Объяснить, что нужно нажимать кнопку в меню бота

✅ Правильно настроенный бот должен:

  • Иметь активный API токен
  • Иметь настроенную кнопку Menu Button → Web App
  • Иметь корректный URL Web App (GitHub Pages)
  • Иметь включенный Inline Mode
  • Открывать WebApp при нажатии кнопки меню

📞 Поддержка

Если после проверки всех настроек проблема сохраняется:

  • Проверьте логи консоли в WebApp
  • Убедитесь, что GitHub Pages обновлены
  • Попробуйте другой браузер или устройство
  • Свяжитесь с поддержкой Telegram или GitHub
