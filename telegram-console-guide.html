🔍 Как открыть консоль разработчика в Telegram WebApp

Важно! Консоль нужна для диагностики проблем с приложением. Без неё сложно понять, что происходит при нажатии кнопок.

📱 Способ 1: Android/iOS + Telegram Desktop

Самый простой способ - использовать Telegram Desktop с подключенным мобильным устройством.

Шаги:

  1. Установите Telegram Desktop на компьютер
  2. Войдите в тот же аккаунт, что и на телефоне
  3. В Telegram Desktop откройте WebApp из бота
  4. Нажмите F12 или Ctrl+Shift+I
  5. Перейдите на вкладку Console
✅ Логи будут отображаться в реальном времени!

🌐 Способ 2: Веб-версия Telegram

Если у вас нет Telegram Desktop, используйте веб-версию.

Шаги:

  1. Откройте web.telegram.org
  2. Войдите в аккаунт
  3. Найдите бота и откройте WebApp
  4. Нажмите F12 или Ctrl+Shift+I
  5. Перейдите на вкладку Console

📲 Способ 3: Мобильный браузер (Android)

Для Android устройств можно использовать мобильный браузер.

Шаги:

  1. В Telegram нажмите на WebApp и выберите "Открыть в браузере"
  2. В браузере (Chrome) нажмите ⋮ → Настройки сайта → Разработка → Включить отладку USB
  3. Подключите телефон к компьютеру по USB
  4. В Chrome на компьютере откройте chrome://inspect
  5. Выберите ваше устройство и страницу
⚠️ Этот способ сложный и требует USB-подключения

💻 Способ 4: Расширение для браузера

Установите расширение для перехвата Telegram WebApp запросов.

Рекомендуемые расширения:

  • Telegram WebApp Inspector - специальное расширение для Telegram
  • User-Agent Switcher - для имитации мобильного браузера

🔧 Способ 5: Локальная разработка

Самый простой способ для тестирования - запуск на localhost.

Шаги:

  1. Запустите приложение локально: npm run dev
  2. Откройте http://localhost:3000 в браузере
  3. Нажмите F12 → вкладка Console
  4. Протестируйте функционал
cd botlab npm run dev

📊 Что смотреть в консоли

После открытия консоли и тестирования приложения вы увидите логи:

🚀 sendSignalToAdmin called 📱 Telegram WebApp available: true 👤 User data: {first_name: "Имя", ...} 📦 Payload to send: {...} 🌍 Environment: production 🔗 API URL: https://web-production-8d8bb.up.railway.app 🔍 Checking server availability... 📡 Server check: 200 📡 Response received: 200 OK ✅ Signal sent successfully 🔒 Attempting to close Telegram WebApp ✅ Telegram WebApp closed successfully

Возможные проблемы:

  • ❌ Failed to send signal - сервер не отвечает
  • 💥 Network error - проблема с интернетом/CORS
  • ⚠️ Telegram WebApp not available - не в Telegram среде
  • 🔄 Falling back to Telegram sendData - используется запасной метод

🧪 Тестирование функционала

После открытия консоли вставьте этот код для ручного тестирования:

// Вставьте в консоль Telegram WebApp testTelegramSend({ service_type: "bot_development_order", action: "order_bot_development", quiz_result: { bot_type: "LINEAR", title: "ИИ-Ассистент (Нейро-сотрудник)" } });

Или используйте готовый отладочный скрипт из файла telegram-debug.js

💡 Совет: Начните с Способа 1 (Telegram Desktop) - он самый простой и надежный!
