🎯 Настройка тестирования Telegram WebApp

🚨 ПРОБЛЕМА: Приложение запущено в обычном браузере, а не в Telegram WebApp!
Поэтому кнопка "Заказать разработку" не работает - Telegram API недоступен.

📱 Способ 1: Telegram Desktop (рекомендуется)

Что делать:

  1. Установите Telegram Desktop с официального сайта
  2. Войдите под тем же аккаунтом, что и на телефоне
  3. Найдите вашего бота в Telegram Desktop
  4. Запустите WebApp из меню бота
  5. Откройте консоль: F12 → вкладка Console
✅ В Telegram Desktop WebApp работает как настоящее мобильное приложение!

🌐 Способ 2: Веб-версия Telegram

Что делать:

  1. Откройте web.telegram.org
  2. Войдите в аккаунт
  3. Найдите бота и запустите WebApp
  4. Нажмите F12 для открытия консоли

🎭 Способ 3: Локальный мок (для разработки)

Если Telegram недоступен, используйте симуляцию для тестирования логики:

🧪 Проверка работы

После настройки Telegram WebApp:

  1. Откройте консоль разработчика (F12)
  2. Вставьте этот код для проверки:
    console.log('Telegram available:', !!(window as any).Telegram);
    console.log('WebApp available:', !!(window as any).Telegram?.WebApp);
    console.log('User:', (window as any).Telegram?.WebApp?.initDataUnsafe?.user);
  3. Пройдите квиз и нажмите "Заказать разработку"
  4. В консоли должны появиться логи отправки данных

Ожидаемые логи успеха:

🚀 sendSignalToAdmin called
📱 Telegram WebApp available: true
👤 User data: {first_name: "Имя", ...}
✅ Signal sent successfully
✅ Telegram WebApp closed successfully

🔧 Диагностика проблем

Если кнопка не работает:

  • Telegram WebApp не инициализирован → Проверьте способ запуска
  • Сервер не отвечает → Проверьте статус railway.app
  • CORS ошибка → Сервер блокирует запросы
  • Сеть недоступна → Проверьте интернет-соединение

Полная диагностика:
